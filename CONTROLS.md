# Controls

Every gameplay key except Esc can be rebound under **Settings → Controls**. The
in-game **How to Play** screen always shows the current bindings.

## Flying

| Action | Default keys | Notes |
|---|---|---|
| Thrust forward | **W** or **↑** | The ship keeps its momentum and drifts when you let go. |
| Reverse thrust | **S** or **↓** | Half power, useful for braking. |
| Rotate left | **A** or **←** | |
| Rotate right | **D** or **→** | |
| Fire | **Space** | Hold to keep firing at the weapon's rate. |
| Boost | **Shift** | A short burst of speed, then a 3-second cooldown. |
| Pause / resume | **Esc** | Not rebindable. |

## Menus

| Action | Keys |
|---|---|
| Move between options | **↑ ↓ ← →** (wraps around at the ends) |
| Choose | **Enter** or **Space** |
| Back / close | **Esc** |
| Mouse | Hover to highlight, click to choose |

On the Controls screen, choose an action and press the new key; **Esc** cancels.
Giving a key to one action removes it from any other action that had it.

## Development builds only

| Action | Key |
|---|---|
| Show or hide the input and movement debug overlays | **F3** |

Release exports remove these overlays.
